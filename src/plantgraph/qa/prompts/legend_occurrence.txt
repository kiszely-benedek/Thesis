How to read the description below. Each node is one drawn symbol (equipment, valve, instrument function or off-page connector) with the sheet_id of the sheet it is drawn on; an item drawn on several sheets is several nodes. send_to is material flow from source to target. send_signal_to, control and measured_by are instrument wiring. Each edge reads source, relation, target: equipment measured_by the transmitter that senses it, a transmitter or controller send_signal_to the next instrument function, and an actuator control the valve it moves, so a control loop runs equipment -measured_by-> transmitter -send_signal_to-> controller -send_signal_to-> actuator -control-> valve. A pipe or signal line that leaves a sheet ends in a FlowOut...OffPageConnector node; that node has a continues_as edge to the FlowIn...OffPageConnector node on the other sheet, from which the line continues. Going from one sheet to the next therefore takes three edges: item, send_to, FlowOut connector, continues_as, FlowIn connector, send_to, next item. Connector and actuator nodes have no tag. same_tagged_item_as links a repeated drawing of an item on another sheet to the main drawing of the same item.
