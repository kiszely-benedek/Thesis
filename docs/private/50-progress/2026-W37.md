**Answer, in the form the dissertation can defend:**
- Ontologies for process plants exist and are serious: IDO / ISO 23726-3 (OWL 2, v4.2 FDIS April 2026), ISO 15926 parts 8 and 12, the PCA RDL, OntoCAPE (dormant since 2009, GPL). CFIHOS is Excel/CSV only.
- DEXPI, which the whole field works on, is **not** an ontology: UML + XML/XSD, zero RDF files in its source-of-truth GitLab (225 entries scanned). But it is anchored to ISO 15926-4, and **105 pyDEXPI class docstrings carry PCA RDL IRIs** that dereference to Turtle today (one verified word-for-word). That is the bridge ADR-0002's RDF loader will use.
- An OWL DEXPI **is being built by TotalEnergies** (dexpi.org news 2026-03-23, BFO + IDO aligned, "still under development"). So "we build the P&ID ontology" is not a defensible contribution. The published DEXPI→OWL demo (Arrowhead fPVN handbook) covers properties and lifecycle zones for one hand-made pump; the word "connector" does not appear in it.
- schema.org V30.0: 823 types, `/Pump` → 404, no valve/pipe/control loop. By design. Wikidata has the concepts but no tag/nozzle/off-page semantics; QUDT is units only (we will use it); SOSA/SSN, Brick/SAREF, IOF do not cover process plants.
- No paper on the reading list uses a formal ontology. Verbatim from 2502.18928: "Node labels are inherited from the pyDEXPI class name and its parent class." ChatP&ID (2603.22528) considers RDF/SPARQL explicitly and declines it for LPG — the trade-off ADR-0002 says to measure.
- DEXPI 1.3 has 16 off-page connector classes (`PipeOffPageConnectorReferenceByNumber` with `referencedDrawingNumber` + `referencedConnectorNumber`), so "no off-page vocabulary" must never be claimed. What it lacks: a drawing-set container (`DexpiModel` = one drawing) and any construct asserting that a tagged item on one sheet is the same item on another. Cross-sheet continuation is an unresolved string pair.
- **Honest gap:** (a) no loadable OWL/SHACL DEXPI today, (b) no use of any vocabulary for retrieval at any scale, (c) no vocabulary or benchmark for identity across drawings. (c) is the contribution; (a) is only its means.

**New find: PIDQA** (Gupta, Wei, Czerniawski, Eiris; MAKE 7(2):39, June 2025) — 64,000 QA pairs over 500 sheets, 128 per sheet, Cypher-generated ground truth, all single-sheet, node labels are the integers 1–32. Largest P&ID QA evaluation in the field. Raises our evaluation bar; does not touch cross-sheet. Full text reachable only as PDF so far — needs `/paper-intake` via an HTML source or the university library.
